# Design Principles

Always-on values behind every interface decision, before any platform specifics.

## Areas under consideration
- [ ] Value hierarchy — when clarity, speed, beauty, and consistency conflict, what wins
- [ ] Feedback rules — every action acknowledged; how immediately and how loudly
- [ ] Restraint policy — what earns visual/motion emphasis; the default is quiet
- [ ] Density preference — spacious vs dense layouts, and when each applies
- [ ] Consistency vs platform-native — when to follow the platform, when to follow the brand
- [ ] Personality — the feel your products share (tone, warmth, sharpness)
