# Security Mindset

Default assumptions and non-negotiables, before any phase-specific security work.

## Areas under consideration
- [ ] Default threat assumptions — what is always treated as hostile (all input? all clients?)
- [ ] Trust boundaries — how they're identified and documented in any system
- [ ] Secrets rules — absolute rules that hold everywhere (never in code, never in logs, …)
- [ ] Data classification defaults — what counts as sensitive, how it's handled by default
- [ ] Least privilege — defaults for tokens, scopes, service accounts
- [ ] Escalation — when a change requires a full threat-model pass vs the baseline
