# Accessibility Baseline

The floor every interface meets before platform-specific a11y work begins.

## Areas under consideration
- [ ] Target standard — WCAG version/level (2.2 AA?) and what it means in practice
- [ ] Non-negotiables — keyboard operability, visible focus, contrast, labeled controls
- [ ] Reduced-motion policy — what every animation must provide as an alternative
- [ ] Color independence — never meaning by color alone
- [ ] When (if ever) a11y work can be deferred, and what must never be
- [ ] How a11y requirements enter the work — design specs, build checklists, or both
