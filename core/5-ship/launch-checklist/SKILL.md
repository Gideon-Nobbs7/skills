# Launch Checklist

The last thing checked before anything goes live.

## Areas under consideration
- [ ] Observability live — logging/metrics/error tracking confirmed working in prod
- [ ] Alarms configured — who/what gets notified when it breaks
- [ ] Rollback rehearsed — the undo path has actually been exercised
- [ ] Verify gates all green — a11y, perf, security sign-offs recorded
- [ ] Comms — who needs to know it shipped
- [ ] Post-launch watch — how long, watching what
