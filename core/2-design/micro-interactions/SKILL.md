# Micro-Interactions

The small details that make software feel great — and the discipline of when to leave them out.

## Areas under consideration
- [ ] Feedback standards — hover, press, focus, selection: what every interactive element does
- [ ] Springs & easing — default curves/physics values, when spring vs duration-based
- [ ] Duration ranges — the ms bands for small/medium/large movements
- [ ] When NOT to animate — frequency rules (high-frequency actions stay instant)
- [ ] Loading & progress feel — spinners vs skeletons vs progress, thresholds for each
- [ ] Reduced-motion equivalents — the required fallback for every effect
